# Administrator Guide: Reports, Settings, Messages and Translation

This chapter covers the **Reports & Analytics** page, the **Settings** page, the **Contact messages** inbox, and how to provide Kinyarwanda versions of your course content.

## Reports & Analytics

Open **Reports & Analytics** in the Analytics group. It needs the View permission for Reports.

### Date range

At the top, set **From** and **To** and press **Apply**; **Reset** returns to the default (the last twelve months). The date range applies to the enrollment figures and the "Enrollments by month" chart. The other tables always cover all time.

### What the page shows

| Section | What it shows |
| --- | --- |
| Key metrics | Students (accounts without admin access), Est. revenue, Enrollments in the chosen period, and Active learners (students who have completed at least one lesson). |
| Engagement | Lesson activity (students with completions), Quiz takers (students with attempts), and, for the last 7 days: New enrollments, Completions (lessons completed) and Quiz submits; plus All-time enrollments. |
| Enrollments by month | Enrollments per calendar month in the chosen range. |
| Revenue by course | For each course: price, enrollments and estimated revenue. |
| Course performance | For each course: enrolled students, number of lessons, how many completed all lessons, the completion rate and the average progress %. |
| Most popular courses | The top 15 courses by number of enrollments, with category. |
| Instructor earnings | For each instructor: courses, total enrollments and estimated earnings. |

How to read the figures:

- **Completion rate** is the percentage of enrolled students who finished every lesson. **Avg %** is the average progress across enrolled students.
- **Est. revenue** and **Est. earnings** are estimates calculated as course price multiplied by the number of enrollments. They are not payment records, because the platform does not process payments. Free courses contribute zero.

Tip: For a per-learner view, use **Student progress** instead. For quiz performance, use **Quiz results**.

## Settings

Open **Settings** in the Site group. The Settings page currently has one setting.

| Setting | Effect |
| --- | --- |
| Platform logo (Upload logo) | The logo shown in the site header and footer. JPEG, PNG, GIF, WebP or SVG, up to 2 MB. A transparent PNG or SVG works best. |
| Remove logo | Tick the box and save to delete the current logo. The site name is then shown instead. |

Steps to change the logo:

1. Open **Settings**.
2. Under **Platform logo**, choose a file in **Upload logo**.
3. Press **Save settings**. A new upload replaces the previous logo.

The page also shows whether a logo is Set or Missing, the number of partner logos, and a **Manage partner logos** button that opens the Partner logos module (see the learners chapter).

Saving needs the Edit permission on Settings.

## Contact messages

Messages sent through the public contact form arrive in **Contact messages**, in the Site group. The Dashboard also shows a banner with the unread and total counts.

- The list shows the sender, subject ("(No subject)" if empty), received date and status (Unread or Read).
- Choose **View** to read a message. Opening it marks it as Read.
- **Delete** removes one message. **Delete read messages** removes all messages already marked Read at once (after confirmation). Unread messages are never removed by this button.
- Deleting needs the Delete permission on Settings.

Note: The inbox shows messages only. There is no reply button, so answer using the sender's email address from the message.

## Translating content into Kinyarwanda

The platform interface is available in English and Kinyarwanda, and learners choose their language with the language switcher. The original text of all content is English. For each piece of content you may add a Kinyarwanda version.

### How to add a translation

1. Open the form for the content (for example a course, lesson or quiz).
2. Fill in the English fields as usual.
3. Open the **Kinyarwanda translation (optional)** section below them.
4. Type the Kinyarwanda text. The grey placeholder shows the English text for reference.
5. Save the form.

To remove a translation, clear the translated fields and save. A course with a translation shows "Kinyarwanda translation available" in the courses list.

### Which fields can be translated

| Content | Translatable fields |
| --- | --- |
| Category | Name |
| Instructor | Name, Bio |
| Course | Title, Description, Duration |
| Section (chapter) | Title |
| Lesson | Title, Text content |
| Bundle | Title, Description |
| Live session | Title, Description |
| Quiz | Title, Description |
| Question | Question text |
| Answer option | Option text |

### What stays English or is not translated

- Any field you leave empty: learners using Kinyarwanda see the English text for that field (the platform falls back to English field by field).
- Content types and fields that are not in the table above: for example user names, partner organization names, partner logo names, role names, meeting links and passwords, course banners and other images, uploaded PDF and video files, and YouTube links. Uploaded PDFs and videos are shown as they are, so upload a Kinyarwanda version as a separate lesson if you need one.
- The admin panel itself: the content lists and forms in the panel keep showing the English originals even when the interface language is Kinyarwanda.
- The interface wording (buttons, menus, messages) is translated separately by the technical team, not through these forms.

Tip: Translate in this order for the best learner experience: category, course, sections, lessons, then quizzes, questions and options.
